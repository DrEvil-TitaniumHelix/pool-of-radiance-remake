# VIEW — screens, menus and messages (lane por-mod-view)

Coordinates are text cells (8×8 px) of the 320×200 screen: row 0..24, col 0..39. Routines: decode/pseudo/VIEW.pas.md. Colours are EGA indices. "Menu" = HorizontalMenu 9D00:03BD on row 24 (prompt colour / text colour / hotkey-and-selection colour as passed by the caller; ExploreCommand passes 0Dh / 0Ah / 0Fh: ordinary letters green, hotkeys and the selected option white — DOSBox capture, fix #ref-2). Generic menu keys everywhere: hotkey letter (capitals and digits of an option), `,` / `.` move the highlight, Enter = highlighted option (returns #13, index in `menu_Sel`), Esc = cancel (#0), Space = #32, extended keys and keypad digits 1..9 when the caller allows them (keypad → End, Down, PgDn, Left, —, Right, Home, Up, PgUp).
