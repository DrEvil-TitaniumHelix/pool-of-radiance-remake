# SCREENS_INDEX — master screen inventory of Pool of Radiance (lane por-screens)

Input for BUILD_PLAN.md: one row per distinct screen (or screen state) the player can see, in game-flow order. Every row names its source row in `decode/pseudo/<AREA>_SCREENS.md` (the full text and the routine addresses are there; the pseudocode is in `<AREA>.pas.md`), the layout, the exact texts, the keys, the pictures (DAX file + record, `decode/data/INDEX.md` / `PICTURES.md`), the next screens, and the DOSBox reference capture in `acceptance/ref/` when one exists (`<id>.png` 640×400, `<id>.native.png` 320×200; checks in `acceptance/ref/DECODE_CHECKS.md`).

Sources used: PARTY_SCREENS (PARTY-*), ENGINE_SCREENS (ENGINE-01..47), ECL_SCREENS (ECL-01..17), VIEW_SCREENS (VIEW-01..12), MAGIC_SCREENS (MAGIC-01..21), COMBAT_SCREENS (COMBAT-01..72). PARTY_SCREENS (PARTY-ov00..ov21, final) is included.

## 0. Common conventions (apply to every row)

- **Screen**: EGA 320×200×16 (POOL.CFG 'E'; 'T' Tandy, else CGA 4 colours — ENGINE-05/16). Text = 40×25 cells of 8×8 glyphs from **8X8D1.DAX record 201 (C9h)**, drawn opaque, always upper-case (`UpCase(ch) mod 64`) — ENGINE-15. Cells are (col,row), 0-based.
- **Colours** (EGA index): 0Ah light green normal text, 0Bh light cyan party names, 0Ch light red inactive names, 0Dh light magenta prompts, 0Eh yellow (monster names, warnings, BIOS disk prompts), 0Fh white (headings, selection, hotkeys). Names: DrawCharacterName colours (ENGINE-39).
- **Frames**: 8×8 symbols 114h..116h of the loaded 8X8D set, drawn one cell outside the rectangle; visible colours come from the glyphs (red/light-red edges, yellow corners), not from a call argument (ENGINE-07, fix #ref-3).
- **Menu line** (HorizontalMenu 9D00:03BD, VIEW-09/MAGIC conventions): row 24; `prompt` in 0Dh, then the option words; ordinary letters green 0Ah, hotkeys (capitals/digits) and the whole selected option white 0Fh (VIEW fix #ref-2). Keys: hotkey letter; `,` / `.` move the highlight; Enter = highlighted option; Esc = cancel; Home/End (scan 47h/4Fh) select the previous/next party member where the caller allows extended keys (CycleSelectedChar).
- **List menu** (VerticalListMenu 9D00:0D9A, VIEW-09): list in the caller's window, header lines not selectable, highlight white; bottom menu = caller's options + ` Next` / ` Prev` (when paged) + ` Exit`; keys letters, Home/End, PgUp/PgDn or N/P, Enter, Esc/E.
- **Yes/No** (AskYesNo 9D00:10D1, VIEW-10): `<prompt>Yes No`, keys Y/N only. **MenuSelect** `~Yes ~No` (ECL-05 rules, Enter not accepted).
- **Messages**: timed bottom message (row 24, 0Ah, GameSpeed×225 ms, cleared — ENGINE-19/37); character message (ENGINE-38: outside combat name at (1,row+1) + text below in the text window; combat right panel cols 23..38 from row 10); bottom prompt + key (ENGINE-18, e.g. `PRESS <ENTER>/<RETURN> TO CONTINUE`); word-wrapped text window with `PRESS ANY KEY TO CONTINUE` paging (ENGINE-17), typewriter delay GameSpeed×10 ms per character for script text.
