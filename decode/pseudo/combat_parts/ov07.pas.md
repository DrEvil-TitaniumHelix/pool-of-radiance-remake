# ov07 (seg 4300) — ECL VM support, encounter display, menus, ECL damage (FINAL pseudocode, lane por-mod-combat)

Unit: ov07, analysis segment **4300** (stub seg 002B, GAME.OVR ofs 0074D3, code 221Ah, 25 entries; init = 4300:2215).
Role: the support half of the event-script VM (operand decoder, VM memory with the character overlay, string variables, packed text, compare flags, gosub stack, IF skip table, block loader), the encounter display (3D sprite / close-up picture / portrait), the hot-key menu helpers used by ECL and other units, and the helpers of ECL opcodes CALL (StepForward, SetupDuel), ROB (ScaleMoney, LoseItemsChance), ENCOUNTER_MENU (PartyMoveRange) and DAMAGE (ApplyEclDamage: " is hit FOR " / " points of Damage.").
Spec: `decode/ecl/ECL_VM.md` (semantics), names: `decode/names/ecl_names.json` (reference; every routine of this unit is named there). Evidence: `decode/listings/ov07.lst`; `.c` only as an aid. Cross-check: lane por-mod-ecl's `decode/pseudo/ECL.pas.md` parts D/E cover the same unit; differences are listed in `ov07_notes.md` §(d).

## Conventions
- Format of `decode/pseudo/VIEW.pas.md`: **signatures in Pascal order** (first parameter = highest BP offset), `name [BP+xx]`; `{ seg:off }` = first instruction of the statement.
- VM notation (ECL_VM.md): `Code[a]` = `ecl_CodeBuf^[a - $9900]` (asm `ES:[DI+6700h]`, DI = buffer + a); `Mem4900[a]`, `Mem6B00[a]`, `Mem9700[a]` = the words of `ecl_Mem4900^/ecl_Mem6B00^/ecl_Mem9700^` at ECL address a (asm `+6E00h` = −2·4900h, `+2A00h` = −2·6B00h, `+D200h` = −2·9700h on `2·a`); `OpType[i]`, `OpLo[i]`, `OpHi[i]` = DS:7005+i / 7085+i / 7045+i (ecl_OpType/OpLo/OpHi, 1-based); `Str[k]` = string[255] at DS:6FC8 + k·100h (ecl_Str0 + k·100h).
- TChar fields by SAVES.md §3 names (`c^.name +00h`, `con +14h`, `cha +15h`, `npc_morale +84h`, `money[0..6] +88h..+95h`, `move +11Ch`, `hp +11Bh`, `status +10Ch`, `active +10Dh`, `side +10Eh`, `controlled +10Fh`, `next +104h`, `items +C8h`, `effects +7Fh`, `party_slot +BFh`); item fields SAVES.md §4 (`next +2Ah`, `weight +37h`).
- Globals by ecl_names.json / view_names.json / magic_names.json names; `Name{g_XXXX}` = introduced here (ov07_names.json); otherwise `g_XXXX`.
- Callees of other units by their **published names** (decode/names/*.json; shown as `;` comments in the re-exported listings), arguments in Pascal order checked against the owners' signatures: VIEW (`RefreshView` A200:016D, `LoadAnimation(name, id, flags, var anim)` AC00:00A2, `DrawPictureScreenOrView(col, row, toView, pic)` AC00:0000, `LoadPortrait(head, body)` AC00:05D9, `DrawPortrait(col, row, both)` AC00:0697, `Show3DSprite(k, anim)` AC00:0708 (order per the asm, see notes §d), `LoadCombatIcon(name, id, slot)` C000:01C8, `HorizontalMenu` 9D00:03BD, `VerticalListMenu` 9D00:0D9A, `ClearMenuLine` 9D00:06FB, `GetWallType(x, y, dir)` B100:047B, `GetCellAttr(x, y)` B100:057A, `LoadWallSet(id, slot)` B100:0E08); ENGINE (`DrawText(col, row, colour, s)` 0709:0626, `DrawWrappedText(x1, y1, x2, y2, colour, clear, s)` 0709:0768, `ShowBottomPromptAndReadKey(colour, s)` 0709:0BF5 (clear row 24, print at col 0/row 24, wait for any key), `ClearTextRectangle(x1, y1, x2, y2)` 0709:0DD3, `DrawPartyRoster(sel)` 00BA:0767, `ApplyDamage(c, dmg)` 00BA:2228, `LoseItem(c, item)` 00BA:1509, `SetDataSet(n)` 0802:094A, `HasEffect(c, id, var e)` 00BA:2199, `LoadDaxRecord(name, ext, id, var size, var p)` 0802:0716); ov24 `Roll(n, s)`. ### 4300:0000 ecl_ReadOperands (H)
`procedure ecl_ReadOperands(n [BP+6]: Byte)` — callers: the ov03 opcode handlers, ecl_InitVM, ecl_SkipInstruction. Callees: ecl_UnpackString, MakeWord, ecl_GetMemString.
Decodes `n` operands following the opcode byte at `ecl_PC` (ECL_VM.md §2) and leaves `ecl_PC` on the next opcode.
```pascal
k := 0;                                                          { 4300:0006  string slot counter }
for i := 1 to n do begin                                         { 4300:000a  skipped when n = 0 }
  OpType[i] := Code[ecl_PC + 1];                                 { 4300:0022 }
  OpLo[i] := Code[ecl_PC + 2];                                   { 4300:003c }
  ecl_PC := ecl_PC + 2;                                          { 4300:0057 }
  case OpType[i] of                                              { 4300:005f }
    1, 2, 3: begin
      ecl_PC := ecl_PC + 1;                                      { 4300:0076 }
      OpHi[i] := Code[ecl_PC];                                   { 4300:007a }
    end;
    $80: begin
      k := k + 1;                                                { 4300:009a }
      len := OpLo[i];                                            { 4300:009d }
      if len > 0 then ecl_UnpackString(len, k)                   { 4300:00ad  reads len bytes, advances ecl_PC }
      else Str[k] := '';                                         { 4300:00c1 }
    end;
    $81: begin
      k := k + 1;                                                { 4300:00d7 }
      ecl_PC := ecl_PC + 1;                                      { 4300:00da }
      OpHi[i] := Code[ecl_PC];                                   { 4300:00de }
      a := MakeWord(OpLo[i], OpHi[i]);                           { 4300:00f7 }
      ecl_GetMemString(k, a);                                    { 4300:0116 }
    end;
  end;                                                           { any other type: 2 bytes consumed, OpHi[i] keeps its old value }
end;
ecl_PC := ecl_PC + 1;                                            { 4300:012c }
```
