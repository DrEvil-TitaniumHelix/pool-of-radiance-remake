# Reading monster records

A monster entry describes a template from the imported game. Its base armour class and base damage are not a prediction of every attack. Equipment, active effects and combat calculations can change the values used during a fight.

The stored record contains pointer values from the original program. Those values are not statistics and are ignored. Item and effect lists come from separate records with the same monster id and data set.

The same name can occur in several data sets with different records. These entries remain distinct. A picture is attached only when an observed event identifies the asset; sharing a record number is not enough to establish a match.
