# Items and identification

An item has a type, name words, a weight and a quantity. The type describes rules such as equipment slot and weapon damage. An individual item can add bonuses or carry powers of its own.

Some name words are hidden until the game identifies them. The pedia keeps those words hidden too. A hidden bonus or curse should not be inferred from the contents of the imported file. An item with no visible name is shown as unidentified.

Readied equipment and carried equipment have different effects. Character calculations rebuild equipment links when a character is loaded; old pointer values in an item file are not usable links.
