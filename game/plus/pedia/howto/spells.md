# Memorising and casting

The character record keeps memorised spell slots separately from the spell book and active effects. A slot marked as pending is a spell selected for study, rather than one ready to cast.

Spell range and duration often combine a base value with a value multiplied by caster level. Some spells have special rules, so the table fields alone do not fully describe the result. Item casting uses its own handling.

An effect list records conditions already applied to a character. It is not a list of spells the character can cast. The pedia keeps effect ids separate from spell ids and does not invent names for unnamed monster or item powers.
